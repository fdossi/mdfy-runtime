# MDfy Runtime

Ambiente público mínimo para as conversões avançadas do [MDfy](https://github.com/fdossi/MDfy).

- **MyBinder + Voilà:** execução temporária sem cadastro.
- **Google Colab:** contingência quando o Binder estiver indisponível.
- Os arquivos são processados somente na sessão temporária e não são armazenados neste repositório.
